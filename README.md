# Наставник — карманный свод и печатные материалы

Комплект для наставника двух братьев (8 и 10 лет): правила, протоколы типовых ситуаций,
план на 90 дней и концепция. Плюс печатные бланки и памятки для папы и мамы.

**Адрес после публикации:** https://artignat2000.github.io/mentor/ (телефон, офлайн, «На экран Домой»)

## Сборка

Нужен Python 3.9+ и, для PDF, пакеты из `requirements.txt`.

```bash
python3 build_print.py   # печатные PDF → print/ и docs/print/
python3 build_site.py    # страница        → docs/index.html (+ nastavnik.html в корне)
python3 make_pack.py     # иконки, манифест, sw.js, zip
```

Порядок важен: `build_site.py` вставляет на главную ссылки на те PDF, которые уже собраны,
и обновляет версию офлайн-кэша в `docs/sw.js` — поэтому после любой правки телефоны подтягивают
новую версию сами, вручную версию поднимать не нужно. `make_pack.py` создаёт сам `sw.js`,
иконки и манифест (это единственный шаг, которому нужен Pillow).

Для PDF нужен шрифт DejaVu с кириллицей (Debian/Ubuntu: `sudo apt install fonts-dejavu-core`).
Если шрифта нет рядом с системой, положите `DejaVuSans*.ttf` в папку `fonts/`.

## Публикация (GitHub Pages)

Источник публикации — **GitHub Actions**: `.github/workflows/pages.yml`. Настраивается один раз:
**Settings → Pages → Source: GitHub Actions**. После этого каждый пуш в `main` публикует сайт сам:

1. `build` — CI пересобирает `docs/index.html` из markdown и обновляет версию офлайн-кэша в `sw.js`.
   Поэтому содержание можно править прямо на GitHub: поправили `.md` → запушили → сайт обновился.
   Локальная пересборка нужна только для PDF и иконок;
2. `deploy` — выкладывает папку `docs/` (страница, иконки, манифест, `sw.js`, PDF) на Pages
   и проверяет, что адрес отдаёт именно страницу свода (если нет — деплой падает с ошибкой).

Адрес: **https://artignat2000.github.io/mentor/**. Ручной запуск и логи — вкладка **Actions**,
workflow «Deploy карманного свода» → *Run workflow*.

На телефоне:

1. Открыть ссылку **в Safari** (не в браузере Telegram — там «На экран Домой» не работает).
2. «Поделиться» → **На экран «Домой»** → Добавить.
3. Значок открывается без адресной строки и работает офлайн (service worker кэширует страницу и иконки).

Если открывается старый вид — потяните страницу вниз для обновления; приложение с домашнего экрана
закройте и откройте заново.

## Как вносить правки в содержание

1. Правите markdown-файлы (источник правды).
2. `python3 build_site.py && python3 make_pack.py`.
3. Коммит и пуш — сайт обновится сам.

Если поменялись формулировки в печатных материалах — их текст лежит в `build_print.py`
(константы `RULES5`, `STOP10`, `PHRASES3`, `SCALE`, `SELF_CHECK` и тексты памяток),
после правки: `python3 build_print.py && python3 build_site.py && python3 make_pack.py`.

повесить на стену, вторые — открыть с телефона.

Для ежедневных отметок используйте `12_listy_poleznyh_del.pdf`: страница 1 — неделя
с крупными клетками, страница 2 — месяц на 31 день. Печатать отдельно каждому ребёнку:
недельный лист — раз в неделю, месячный — раз в месяц. Свой пункт выбирается по желанию;
баллов и сравнения братьев нет. Прежние карта утра и дневник силы остаются в комплекте.

Печатать **100 %, без «по размеру страницы»**; поля «нет» или 5 мм.

## Закрытый раздел для родителей

`docs/semya.html` — необъявленная страница для папы и мамы: на неё нигде нет ссылки, она
не входит в поиск по своду, в манифест и в офлайн-кэш. Содержимое хранится **только
шифротекстом** (AES-256-GCM, ключ из кода через PBKDF2-SHA256, 310 000 итераций);
расшифровка — в браузере, через WebCrypto. Без кода страница показывает форму ввода.

- исходный текст — `secret_roditeli.md`, он в `.gitignore` и в репозиторий не попадает;
- код в репозитории не хранится: сборка спрашивает его (`getpass`) или берёт из переменной
  `PARENTS_CODE`, а печатает готовую ссылку вида `semya.html#k=…`;
- пересобрать с новым кодом: `python3 build_secret.py` (нужен пакет `cryptography`);
- в `nastavnik_pack.zip` раздел не попадает (`SKIP_FROM_PACK` в `make_pack.py`).

Честная граница: сайт статический и репозиторий публичный. Код защищает от того, кто
открыл ссылку и не знает пароля, но не от того, кто целенаправленно полезет в исходники
и станет перебирать код. Для настоящей приватности нужен приватный репозиторий и хостинг
с паролем на стороне сервера.

## Семейное приложение-справочник

Контур `family/` — справочник «Родители / Дети» без ввода данных. На GitHub Pages
открыты оба раздела, без входа и пароля:

- **Семья:** https://artignat2000.github.io/mentor/family/
- **Родителям:** https://artignat2000.github.io/mentor/parents/

В «Родителям» опубликованы правила для папы, правила для мамы и методика
«Отказ пылесосить» (`family/content/parents/metodika-pylesos.md`). Страницы
адаптированы для телефона и имеют версию для печати.

- Статическая сборка обоих разделов: `python3 -m family.build_public` → `docs/family/` и `docs/parents/`.
- Серверный режим с отдельным входом сохранён: `python3 -m family.server --family-port 8000 --parents-port 8001`.
- Открытая публикация не защищает материалы паролем: всё, что добавлено в индексы этих контуров, доступно по ссылке.

Подробнее: `family/README.md`.

## Что в этом комплекте намеренно не сделано

Нет баллов, звёздочек, рейтингов между братьями и «доски позора»: любая система, где
братья соревнуются, усиливает ровно то, с чем мы боремся. Это решение, а не недоделка.
