# HANDOFF — передача проекта в новый чат

**Дата обновления:** 31.10.2026
**Что это:** сводный бриф, чтобы новый чат мог продолжить работу без чтения истории переписки.
Приложите к первому сообщению репозиторий (или архив `nastavnik_pack.zip`, его собирает `make_pack.py`) и текст ниже.

## 1. Задача проекта (в двух словах)

Двое братьев, 8 и 10 лет. Воспитанием занимается **папа**. Есть **наставник** — папин товарищ, которого мальчики знают давно и с которым у них есть общий спортивный опыт: он видел их в нагрузке и в проигрыше, и это его сильная сторона. Наставник на связи с папой по телефону, встречи 2–3 раза в неделю на нейтральной территории (кафе, прогулки, отдельная квартира, рыбалки/походы). Форматы: вчетвером с папой, наставник + двое мальчиков, наставник + один мальчик.

**Проблемы, с которыми работаем:**
- Старший (10) очень талантлив (фортепиано, IT), но эмоционально нестабилен: истерики, ревность к маме из-за младшего. Цель — самообладание, а не подавление эмоций.
- Младший (8) менее эмоционален, но «подхватывает» крик старшего.
- В доме не должно быть места ссорам, ревности и крику.
- Нужен режим дня: подъём → контрастный душ → зарядка (обязательно турник) → завтрак → созидательное дело (фортепиано / шаг в IT-проекте / полезное видео) → одно доброе дело для брата или родителей → вовремя отбой.

**Контент (не трогать без запроса):**
- `koncepciya_nastavnichestva_v1.md` — концепция, 5 исследовательских опор, ядро «РИТМ — ПАУЗА — ПОСТУПОК».
- `01_pravila_nastavnika.md` — 65 правил в 11 разделах, 10 стоп-правил, чек-лист «я сбился».
- `02_protokoly_tipovyh_situaciy.md` — 13 протоколов на типовые ситуации.
- `03_plan_90_dney.md` — план на 3 месяца, 5 метрик, правило возврата.
- `00_README.md` — карта комплекта.

## 2. Техническая архитектура

```
.github/workflows/pages.yml   деплой docs/ на GitHub Pages (источник: GitHub Actions)
*.md                   источник правды (контент)
build_site.py          markdown → docs/index.html + копия nastavnik.html
build_print.py         письменные материалы → print/*.pdf и docs/print/*.pdf
printkit.py            мини-набор вёрстки для PDF (reportlab, шрифты DejaVu)
make_pack.py           иконки, manifest, sw.js (кэш), zip-архив
docs/                  ← это публикует GitHub Pages (Settings → Pages → /docs)
print/                 те же PDF + README «что сколько печатать»
requirements.txt       Pillow, reportlab, segno (только для сборки)
```

**Сборка:**
```bash
python3 build_print.py && python3 build_site.py && python3 make_pack.py
```
Порядок важен: `build_site.py` вставляет ссылки на уже собранные PDF и обновляет версию
офлайн-кэша в `docs/sw.js` (вручную её поднимать не нужно). В CI выполняется только
`build_site.py` — он без зависимостей, поэтому деплой работает без Pillow/reportlab.

**Ключевое требование к сайту:** страница должна работать **без JavaScript**.
Причина: на iPhone локальный HTML, открытый через приложение «Файлы» (Quick Look), не выполняет JS.
Поэтому:
- навигация между разделами — CSS `:target` (вкладки — обычные `<a href="#r">`), активная вкладка подсвечивается через `body:has(#r :target)`;
- аккордеоны — нативные `<details>/<summary>`;
- JS — только прогрессивное улучшение: поиск по своду + авто-раскрытие `<details>` по хэшу + регистрация service worker.

**Структура страницы:** 5 панелей — `#home` (главное), `#r` (правила), `#p` (протоколы), `#pl` (план), `#k` (концепция). Карточки имеют id: протоколы `p1…p13` (открыты по умолчанию), правила `r0…r11`, план `pl1…pl12`, концепция `k1…k11`. Ссылки с главного экрана ведут прямо на `#p1`, `#p10` и т. д.

**Осторожно при правках CSS:**
- селекторы `:has()` — сознательный выбор (Safari 15.4+); при отсутствии поддержки деградация мягкая (главная панель остаётся видимой над целевой);
- `scroll-margin-top` на `.pane` и `details` компенсирует липкую шапку (78–84 px);
- не добавлять внешних шрифтов/скриптов/CDN: файл должен оставаться автономным.

**PWA:** `docs/manifest.webmanifest`, `docs/sw.js` (версия = хэш `index.html`), иконки `icon-180/192/512.png` (генерирует `make_pack.py`).

**Печатные материалы:** всё A4, карточки — A5 по две на альбомном A4 с меткой разреза. Шрифт DejaVu
(системный пакет `fonts-dejavu-core` или папка `fonts/`). Текст печатных формулировок живёт
в `build_print.py` (константы `RULES5`, `STOP10`, `PHRASES3`, `SCALE`, `SELF_CHECK` и тексты памяток) —
менять там и пересобирать, а не править PDF руками. Вёрстка двухпроходная: сначала считается
высота блоков, потом остаток распределяется по отступам, поэтому листы не «съезжают».

## 5. Правила работы с этим проектом

- Язык — русский, тон спокойный и конкретный, без мотивационного пафоса.
- Источник правды — **markdown-файлы**; `docs/index.html`, `nastavnik.html` и PDF всегда
  пересобираются скриптами, вручную не правятся.
- В контенте намеренно **нет** баллов, рейтингов, сравнений между братьями и «доски позора» —
  это принципиальное решение, не «недоделка».
- Всё, что касается отношений взрослых (папа/мама), наставник не комментирует и не оценивает —
  это заложено в правилах, не смягчать. Памятка маме поэтому начинается с «это не оценка
  вашего воспитания».
- Пользователь предпочитает сначала общую концепцию, потом детализацию; просит проверять акценты,
  а не додумывать.
