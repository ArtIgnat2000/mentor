# Семейный справочник: Родители / Дети

Это справочник, а не трекер. Данные не вводятся и не синхронизируются.

## Контуры

- **Семья** — публичный детский/общесемейный контур. Только материалы, которые можно показывать детям.
- **Родителям** — отдельный закрытый контур. Серверный вход, индивидуальные аккаунты, закрытые страницы не кэшируются офлайн.

Наставнический контур здесь не реализован и не должен попадать в эти два приложения.

## Запуск

```bash
python3 -m family.server --family-port 8000 --parents-port 8001
```

При первом запуске родительский контур напечатает токен первичной настройки. Откройте `/setup` на родительском порту, введите токен и создайте первого родителя. После этого токен удаляется.

Для production:

```bash
FAMILY_SESSION_SECRET='длинный-случайный-секрет' python3 -m family.server --production
```

Production требует HTTPS,.reverse proxy и секрет сессии. GitHub Pages не подходит для закрытого родительского контура, потому что не проверяет доступ на сервере.

## Контент

- `family/content/family/` — только детские/общие материалы.
- `family/content/parents/` — закрытые родительские материалы и методики.
- `index.json` в каждой папке задаёт список страниц.

Чтобы добавить методику:

1. Положите markdown-файл в `family/content/parents/`.
2. Добавьте запись в `family/content/parents/index.json`.
3. Перезапустите сервер или обновите страницу: контент читается с диска.

Не кладите закрытые методики в `content/family/`, `docs/`, `print/` или публичный репозиторий, если они не должны быть видны детям/наставнику.

## Безопасность

- Пароли родителей хранятся как PBKDF2-хеши в `instance/parents.json`.
- Сессии подписываются HMAC, cookie HttpOnly/SameSite.
- Закрытые ответы имеют `Cache-Control: no-store`.
- Service worker родительского контура кэширует только оболочку и статику, но не закрытые страницы.
- Семейный контур физически не читает `content/parents/`.
