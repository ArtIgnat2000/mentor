# Семейный справочник: Родители / Дети

Это справочник, а не трекер. Данные не вводятся и не синхронизируются.

## Что опубликовано на сайте

На GitHub Pages открыты разделы без входа и пароля:

- **Детям** — https://artignat2000.github.io/mentor/children/
- **Семья** — https://artignat2000.github.io/mentor/family/
- **Родителям** — https://artignat2000.github.io/mentor/parents/

### Детский раздел

Отдельная страница с более лёгким дизайном и крупными карточками:
- «Наши правила»;
- «Если трудно» — злость, ссора, ошибка, отказ от дела, просьба о помощи;
- «Мой день» — утро, дела, отдых, минимум в трудный день;
- «Мои листы и материалы» — все детские PDF и правила в одном месте.

### Родителям

Рабочий инструмент для текущих задач:
- общие правила для взрослых;
- отдельные правила для папы и для мамы;
- правила для детей, чтобы освежить договорённости;
- 12 типовых ситуаций с шагами и готовыми фразами;
- методика «Отказ пылесосить»;
- печатные формы: ежедневные дела, добрые дела, зарядка/турник, утро, пауза,
  итоги недели, самопроверка взрослого;
- у каждой формы — инструкция, пример заполнения и пример анализа;
- поиск, фильтры по темам, быстрые действия, мобильная вёрстка и печать.

Важно: статическая публикация открыта любому, у кого есть ссылка. Не кладите в
индексы и контент этих разделов личные, секретные или не предназначенные для
публикации материалы.

## Пересборка открытой версии

```bash
python3 build_print.py          # PDF, если менялись печатные формы
python3 build_site.py           # главная страница наставника
python3 -m family.build_public  # children/ family/ parents/
python3 make_pack.py            # иконки, манифест, корневой sw.js, архив
```

Экспортёр читает только страницы, перечисленные в `index.json` каждого контура.
Служебный шаблон `_template-metodika.md` не публикуется.

## Контент

- `family/content/children/` — детские страницы.
- `family/content/family/` — общие семейные материалы.
- `family/content/parents/` — родительские правила, ситуации, формы и методики.
- `index.json` в каждой папке задаёт список страниц, группы, иконки, ключевые
  слова и ссылки на PDF.
- Правила детей и взрослых собираются из `family_rules.py`, чтобы сайт и PDF не
  расходились.
- Типовые ситуации лежат в `family/content/parents/situacii.md` и собираются в
  раскрывающиеся карточки с якорями.

Чтобы добавить материал:

1. Положите markdown-файл в нужную папку контура.
2. Добавьте запись в `index.json`: `slug`, `title`, `summary`, `source`, `group`,
   `icon`, `keywords`, при необходимости `resources`.
3. Пересоберите открытую версию и опубликуйте изменения.

## Печатные формы

PDF собирает `build_print.py`. Основные листы:
- `17_ezhednevny_list_del.pdf` — один день;
- `12_listy_poleznyh_del.pdf` — неделя и месяц;
- `06_kopilka_dobryh_del.pdf` — добрые дела;
- `10_dnevnik_sily.pdf` — зарядка, турник, итоги;
- `02_karta_utra.pdf` — утро;
- `03_karta_pauzy.pdf` и `04_shkala_1_5.pdf` — пауза и состояние;
- `11_itogi_nedeli.pdf` — разговор в конце недели;
- `07_proverka_ya_sbilsya.pdf` — самопроверка взрослого.

Инструкции, примеры заполнения и анализа лежат в родительских страницах
`forma-*.md`. Примеры вымышленные и не оценивают реальных детей.

## Серверный режим

В репозитории сохранён отдельный серверный режим с двумя портами и входом для
родительского контура:

```bash
python3 -m family.server --family-port 8000 --parents-port 8001
```

При первом запуске родительский контур напечатает токен первичной настройки.
Откройте `/setup` на родительском порту, введите токен и создайте первого родителя.
После этого токен удаляется.

Для production:

```bash
FAMILY_SESSION_SECRET='длинный-случайный-секрет' python3 -m family.server --production
```

Production требует HTTPS, reverse proxy и секрет сессии. Серверный вход не делает
секретными материалы, которые уже опубликованы в открытой статической версии.

## Безопасность серверного режима

- Пароли родителей хранятся как PBKDF2-хеши в `instance/parents.json`.
- Сессии подписываются HMAC, cookie HttpOnly/SameSite.
- Закрытые ответы серверного режима имеют `Cache-Control: no-store`.
- Service worker серверного родительского контура кэширует только оболочку и статику.
- Семейный серверный контур физически не читает `content/parents/`.

Открытая версия на GitHub Pages устроена иначе: она специально публикует разделы
без входа и кэширует их для офлайн-чтения.
